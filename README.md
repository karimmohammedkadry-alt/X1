# X1 — Luxury Contemporary Streetwear

واجهة متجر X1 الأمامية فقط، مبنية باستخدام React وTypeScript وVite. لا تحتاج إلى Backend أو قاعدة بيانات لتشغيل واجهة المتجر.

## التشغيل محلياً

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
```

افتح الرابط الذي يظهر في الطرفية (غالباً `http://localhost:5173`).

## بناء نسخة النشر

```bash
npm run build
```

سيتم إنشاء الموقع الجاهز للنشر داخل مجلد `dist/`.

## النشر على GitHub Pages

1. ارفع محتويات هذا المشروع إلى مستودع GitHub، واجعل اسم الفرع `main`.
2. افتح **Settings → Pages**.
3. من **Build and deployment** اختر **GitHub Actions**.
4. ادفع أي تحديث إلى `main`؛ سير العمل الموجود في `.github/workflows/deploy.yml` سيبني الموقع وينشره تلقائياً.

تم ضبط Vite على مسارات نسبية حتى يعمل الموقع داخل رابط GitHub Pages الخاص بالمستودع، وكذلك على الاستضافات الأخرى.

## حدود نسخة Frontend فقط

- المنتجات والمراجعات معرفة داخل ملفات المشروع.
- السلة والمفضلة والتصفية والمقارنة وتجربة الواجهة تعمل داخل المتصفح.
- لا يوجد Backend أو قاعدة بيانات أو لوحة إدارة.
- تأكيد الطلبات والنماذج في هذه النسخة تجريبي/محلي؛ لا يتم حفظ الطلبات في نظام مركزي ولا إرسالها تلقائياً إلى المتجر. يلزم ربط خدمة خلفية أو خدمة نماذج/طلبات لاحقاً لاستقبال الطلبات فعلياً.
- لا تضع مفاتيح API سرية داخل كود Frontend أو مستودع GitHub عام.
